The problem

Most of the web still locks people out

Fixing it by hand is slow, so it rarely gets done. Automation makes the common failures cheap to find and cheap to fix.

How it works

From audit to verified fix in five steps

Open an inaccessible site, find the problems, generate an accessible version, and check that it worked.

  1. Crawl

    Playwright

    Loads the page, walks the real tab order and captures screenshots.

  2. Audit

    axe-core

    Runs the standard rules plus custom checks for focus, target size, timers and support options.

  3. Perceive

    OCR

    Reads text inside images so banners and product photos get useful alt text.

  4. Repair

    DOM patch

    Applies safe fixes and flags anything that needs judgement, with a change list.

  5. Verify

    Re-audit

    Scans again and recomputes the score, so each fix is checked.

Who it helps

Three groups, specific checks

Each group gets the rules that matter for them, not a generic score.

Visually impaired users

  • Contrast of at least 4.5:1 for text and 3:1 for large text, with no colour-only meaning
  • Text that scales to 200–300% without breaking the layout
  • Headings, landmarks and alt text for NVDA, JAWS and VoiceOver
  • Light, dark and high-contrast modes in built-in settings, not an overlay

Hearing-impaired users

  • Synchronised captions and full transcripts for video and audio
  • Text-based support: chat, email and text, not phone alone
  • Plain, direct language with a readability check

Motor-impaired users

  • Every control reachable and usable by keyboard, with a visible focus indicator
  • Large click targets, 44 pixels or more
  • No hard time limits: pause, extend or turn off
  • Short forms with clear errors and suggested fixes

Not an overlay

Fixes you can read, review and keep

Accessibility overlays paint a widget over the page and often get in the way of assistive technology. AccessForAll changes the markup itself, shows each change in a list, and marks anything generated, such as alt text, for a person to confirm.

Automated tools catch only part of what matters. Treat the report as a fast first pass, then test with real users and assistive technology.

Questions

Straight answers

Is this an accessibility overlay?

No. Overlays add a widget on top of a page. AccessForAll edits the page’s own markup and lists every change so you can review it.

Can it make a site fully compliant?

No tool can. Automation finds and fixes many common failures, and flags the rest. Judgement calls such as alt text wording stay marked for review, and real-user testing is still needed.

Does it change my live site?

The extension patches the page in your own browser, so you can see the accessible version and export the list of changes. Applying them to your source code is up to you.

What does it cost?

It is designed as an open-source project, free to use and to inspect.
