              Under the hood

              From audit to verified fix

              The same pipeline powers the live scan above, the extension popup and a command-line run for CI.

              1. Crawl

                Playwright loads the page, walks the real tab order and captures screenshots for the OCR step.

              2. Audit

                axe-core plus custom rules for focus visibility, target size, timers and contact options.

              3. Perceive

                OCR reads text inside images, so banners and product shots get meaningful alt text.

              4. Repair

                Safe fixes patch the DOM. Anything that needs judgement is marked for review, with a change list.

              5. Verify

                The page is audited again and the score is recomputed, so every fix is checked, not assumed.
